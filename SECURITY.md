# Security policy

AutoBSKAN is a local scientific application. The GUI can read paths available to
the user who launched it and accepts large file uploads into a temporary
directory. Keep the default `127.0.0.1` host on workstations containing private
or licensed calculation data. Do not expose the server to an untrusted network.

Report a security issue privately to `lgy4230@yonsei.ac.kr`. Include the affected
version, operating system, reproduction steps, and impact. Do not open a public
issue until the maintainers have assessed disclosure.

Security fixes are supported on the latest released version.
